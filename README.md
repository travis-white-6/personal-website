# traviswhite.dev

Personal website for Travis White.

Live at [traviswhite.dev](https://traviswhite.dev)

## Stack

- [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org/) (Create React App)
- Hosted on [Firebase Hosting](https://firebase.google.com/docs/hosting)

## Development

```bash
npm install
npm start        # http://localhost:3000
```

## Deployment

```bash
npm run build
firebase deploy  # requires firebase login
```
